03 — Featured Project

BOM Cost & Supplier Analytics

Real costing logic, rebuilt in SQL
SQL · SQLITE

Recreates the BOM costing and RFQ analysis I did manually in Excel at Amphenol — consolidating BOMs, comparing supplier quotes against standard cost, and flagging cost/lead-time risk. Synthetic dataset modeled on that real structure: 40 parts, 5 suppliers, 4 product BOMs, 93 RFQ quotes.

-- Cost-savings opportunities: latest quote beats standard cost
SELECT p.part_number, p.unit_cost, latest.quoted_unit_cost,
    p.unit_cost - latest.quoted_unit_cost AS savings_per_unit
FROM parts p
JOIN (SELECT ... WHERE quote_date = MAX(quote_date)) latest
  ON latest.part_id = p.part_id
WHERE latest.quoted_unit_cost < p.unit_cost;
